# Simple Customer Invoice System

A streamlined invoice system that follows your exact workflow:

## 🎯 **Your Workflow - Step by Step:**

### **Step 1: Enter Customer Details**
The system will ask for:
- **Shop Name** (e.g., "Super Market Plus")
- **Customer Name** (shop owner's name, e.g., "Ahmed Khan") 
- **Area** (location, e.g., "Downtown District")
- **Contact** (optional phone/email)

Click **"Confirm Customer Details"** to proceed.

### **Step 2: Add Products**
For each product, enter:
- **Product Name** (e.g., "Rice Bags 50kg")
- **Quantity** (e.g., 10)
- **Unit Price** (e.g., 45.00)

Click **"Add Product"** for each item.
The total is calculated automatically.

### **Step 3: Generate Invoice**
Click **"Generate Invoice & Save"** and the system will:
- Create a professional Excel invoice
- Save it with the customer's name
- Store all customer details

## 📁 **File Naming:**
Invoice files are saved as:
`Invoice_CustomerName_YYYYMMDD_HHMM.xlsx`

Example: `Invoice_Ahmed_Khan_20250928_1430.xlsx`

## 🚀 **How to Run:**
Double-click: `run_simple_invoice.bat`
